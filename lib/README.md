# Driver JDBC

`mysql-connector-j-8.4.0.jar` foi obtido do Maven Central:
https://repo.maven.apache.org/maven2/com/mysql/mysql-connector-j/8.4.0/

O projeto NetBeans inclui o JAR no classpath de compilação e execução.
Esta versão é compatível com MySQL Server 8.0 e posteriores:
https://dev.mysql.com/doc/relnotes/connector-j/en/news-8-4-0.html

As informações de licença estão em `LICENSE` dentro do JAR.
